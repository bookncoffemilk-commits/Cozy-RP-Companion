# Cozy RP Companion for SillyTavern

A beautiful, draggable, and highly customizable HUD (Head-Up Display) extension for [SillyTavern](https://github.com/SillyTavern/SillyTavern). 
It tracks your current scene state, companion details, player status, and context memory, wrapping it all in a polished UI with dynamic atmospheric particles.

## ✨ Features
- **Draggable Crystal Trigger:** A sleek, non-intrusive diamond icon that you can drag anywhere on your screen.
- **Scene Tracker:** Live inputs for Location, Room, Time, and Weather.
- **Character Status:** Track outfits, items held, and physical status for both the Companion and the Player.
- **Context & Tokens:** Visual progress bar for your context memory.
- **4 Dual-Tone Themes:**
  - 🌸 **Sakura:** Deep plum base, pink accents, soft green details.
  - 🌲 **Forest:** Forest green base, bright moss accents, berry red details.
  - 🍂 **Autumn:** Dark brown base, amber/orange accents, olive green details.
  - 💜 **Lavender:** Night blue base, lavender accents, warm star-yellow details.
- **Atmospheric Particles:** Custom floating dust motes and falling effects tailored to each theme.

## 📦 Installation
1. Open your SillyTavern installation folder.
2. Navigate to `public/scripts/extensions/third-party/`.
3. Create a folder named `cozy-companion`.
4. Drop all the files from this repository (`index.js`, `style.css`, `manifest.json`) into that folder.
5. Refresh SillyTavern.
6. Click the crystal 💎 icon in the bottom left corner to open the panel!

## 🎨 UI Architecture
Built with a strict Dual-Tone Dark Mode philosophy to ensure perfect readability and visual depth without losing the atmospheric color accents.
